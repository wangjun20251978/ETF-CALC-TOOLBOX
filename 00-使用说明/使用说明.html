使用说明 · 本机买断版

单文件离线工具 · 无需安装 · 无需注册 · 无需联网
一次买断，永久使用 · 数据只存在你自己的电脑里

1怎么打开

拿到的文件是一个 .html 后缀的文件。它不是一个需要安装的软件，双击就能用。

A
电脑 推荐 把文件保存到桌面 → 双击它 → 用浏览器打开，立刻可以用。
不必安装任何东西，不必注册账号，拔了网线也能用。
B
安卓手机 可以 在微信里收到文件 → 点开它 → 右上角 「…」 → 用其他应用打开 → 选浏览器（Chrome / QQ浏览器 / 夸克 都行）。
C
iPhone 步骤较多 微信里点开文件 → 右上角 「…」 → 用其他应用打开 → 存储到「文件」→ 打开系统自带的「文件」App → 找到它 → 长按 → 共享 → 用 Safari 打开。

打不开？多半是浏览器太旧。换成 Chrome 或 Edge 再试一次，就没问题了。

2你填的数据存在哪里

存在你自己这台设备的浏览器里，不会上传到任何地方，我们也看不到。这是这个版本的特点——数据不出门。

  • 换一台电脑打开 → 是空白的，需要重新填一遍
  • 清理浏览器缓存、或用无痕模式打开 → 填过的内容会丢
  • 想长期保留：填完后截图留档，或用页面上的「打印 / 存 PDF」保存一份
  • 不要把重要数据只留在这个页面里——它不是账本，是个计算工具

3里面的行情数据说明（重要）

产品里内置了一份 ETF 的历史行情快照，方便你打开就有数据可以试，不用手动粘。

但它是离线产品，抓不到当天的实时价。所以：

  • 内置的那份数据会过期，页面上标注了快照日期，用之前先看一眼
  • 正式算之前，把「现价 / 基准价」改成你在券商软件上看到的真实价格
  • 改现价不影响其他参数，也不影响历史的形态判断

如果你需要实时行情自动带入，那是另一个版本的事，可以单独问。

4页面上的东西怎么看

顶部「选标的」下拉选一只 ETF，名称、价格、数据会自动带进去。选「自定义」可以自己手填任意代码。
方案按钮点一下，整套参数自动就位，下方会展开一张说明卡，写清这个方案用在哪、会看到什么、要注意什么。
颜色按 A 股习惯：红色 = 涨 / 买入档，绿色 = 跌 / 卖出档。
打印 / 存 PDF把当前结果存成一份 PDF 留档，格式已经排好，直接打就行。

5常见问题

双击打开是一片空白，或者没反应？
先确认文件后缀确实是 .html（有的聊天软件会自动改名）。再确认用的是 Chrome / Edge 这类现代浏览器。还不行，右键 → 打开方式 → 选浏览器。
算了半天，数字一直不变？
检查输入框里是不是混进了汉字、空格或全角符号，比如把 1.05 打成了 1.05元。数字框里只填数字。
可以装到手机上像 App 一样用吗？
可以。用手机浏览器打开后，选「添加到主屏幕」，桌面就会出现一个图标，点开是全屏的，和 App 一样。
能发给朋友用吗？
一个文件对应一台设备使用。要多人用，请为每一台单独获取。
会不会算错？
页面里的公式都是公开的常规算法（网格、均线、布林、斐波、回撤、盈亏等），没有黑箱。不过任何计算工具都依赖你输入的数据，输入错了结果一定错，请核对后再用。
