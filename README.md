# 券商付费功能 · 五大实用工具

把券商 APP 里常见的付费看盘功能，做成打开网页就能用的在线计算工具。五个工具只做数据加工与数学计算，不构成任何投资建议。

## 工具

1. 网格计算器 —— 自动算买卖档位、区间回测
2. 神奇九转计数器 —— 九转序列自动计数
3. 持仓体检器 —— 回撤与风险一键体检
4. 撑压位计算器 —— 多法共振支撑压力位
5. 条件单策略计算器 —— 止盈止损分批情景推演

数据快照存于 `_data/etf48_snapshot.json`，页面每 30 分钟尝试从腾讯公开行情接口刷新当前价，失败时回退到内置快照。
